

🥚 Egg Timer<3 — Cozy Productivity App

A cute and cozy productivity desktop application designed to make studying and working more enjoyable through interactive animations, relaxing ambience, and a virtual pet companion.

✨ Features

- ⏱️ Interactive Timer: A draggable timer box for managing focus sessions.
- 🥚 Egg Hatch Animation: Adds a fun and rewarding touch to productivity sessions.
- 🧸 Interactive Pet Companion: A cute companion that brings personality to the focus experience.
- 🎀 Welcome Modal: A teddy bear greets users when they open the application.
- 🌊 Ambient Sounds: Relaxing ambience to create a comfortable working environment.
- 🌊 Ocean Wave Generation: Dynamic ocean waves during ocean ambience.
- 🎨 Theme Ambience: Cozy visual themes for a personalized experience.
- 🔍 Zoom Controls: User-friendly interface zooming.
- 🥺 Farewell Animation: A sad teddy appears when users leave the application.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Electron.js

🚀 Getting Started

Prerequisites

Install "Node.js" (https://nodejs.org/) and npm.

Installation

1. Clone the repository:
   
   git clone https://github.com/Dharshini-dev-cmyk/egg-timer.git

2. Navigate to the project folder:
   
   cd egg-timer

3. Install the dependencies:
   
   npm install

4. Start the application using the script configured in "package.json":
   
   npm start
